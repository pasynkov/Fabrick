## ADDED Requirements

### Requirement: MCP server exposes routing instructions to the client

MCP server SHALL pass an `instructions` string to the `Server` constructor via `ServerOptions`. The instructions SHALL tell the LLM to call `fabrick_search` only when the question requires knowledge from a different service, layer, or repository than the one currently in context. The instructions SHALL explicitly state not to use the tool for questions answerable from local context.

#### Scenario: Client receives routing instructions on connect
- **WHEN** an MCP client connects to the fabrick MCP server
- **THEN** the client receives server-level instructions stating when to use `fabrick_search`
- **AND** the instructions reference the project name

#### Scenario: Instructions do not override tool description
- **WHEN** both `instructions` and `mcp-description` tool description are present
- **THEN** both are surfaced to the LLM without conflict
- **AND** instructions govern behavior, description governs knowledge-map

### Requirement: mcp-description includes "When to use" section

The `mcp-description` wiki page generated by synthesis SHALL include a `## When to use` section. The section SHALL list concrete cross-layer trigger examples based on the actual layers/apps present in the project (e.g., frontend → backend, backend → infra). The section SHALL NOT instruct the LLM to always use the tool.

#### Scenario: When-to-use section matches project structure
- **GIVEN** project contains frontend, backend, and infra repos
- **WHEN** synthesis generates mcp-description
- **THEN** the "When to use" section lists cross-layer examples covering all three layers

#### Scenario: Single-layer project omits irrelevant triggers
- **GIVEN** project contains only backend repos
- **WHEN** synthesis generates mcp-description
- **THEN** the "When to use" section lists only relevant cross-boundary scenarios (e.g., "need deployment config")
- **AND** does not fabricate cross-layer examples for absent layers

#### Scenario: "When to use" does not say always use
- **WHEN** synthesis generates mcp-description for any project
- **THEN** the "When to use" section does not contain language like "always use this tool" or "use for every question"

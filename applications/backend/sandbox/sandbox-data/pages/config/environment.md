# Environment Config

All ConfigMaps live in `base/configmaps/`. Applied before applications in the kustomize resource order.

## main-postgres-configmap

Injected into: `assets-registry`, `harvester-conductor`

| Key | Value |
|-----|-------|
| `POSTGRES_HOST` | `postgres.internal.namico.io` |
| `POSTGRES_USER` | `postgres` |
| `POSTGRES_PORT` | `5432` |
| `POSTGRES_PASSWORD` | `XGG?mfYa{Gm9!YS2}` |

Each service overrides `POSTGRES_DATABASE` via its own env var (`assets_registry` or `harvester`).

## kafka-brokers-configmap

Injected into: `harvester-conductor`, `harvester-reaper`, `kafka-ui`

| Key | Value |
|-----|-------|
| `KAFKA_BROKERS` | `kafka-server.internal.namico.io:9092` |
| `KAFKA_ZOOKEEPERS` | `kafka-server.internal.namico.io:2181` |
| `KAFKAJS_NO_PARTITIONER_WARNING` | `1` |

Kafka is external (not in-cluster).

## nats-servers-configmap

Injected into all applications.

| Key | Value |
|-----|-------|
| `NATS_SERVERS` | `nats://nats-cluster-headless.harvester.svc.cluster.local:4222` |

Points to in-cluster NATS headless service.

## gcp-service-account-key (ConfigMap)

Generated by `configMapGenerator` from `./gcp-key.json` → mounted as `/etc/secrets/key.json` in all GCP-enabled pods. Referenced by: `binance-vision`, `harvester-conductor`, `harvester-reaper`, `nasdaq-cloud-storage`, `kafka-bigquery-connect`.

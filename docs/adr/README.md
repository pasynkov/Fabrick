# Architecture Decision Records

Repository-wide ADRs. One file per decision. Format: lightweight Nygard
(Context / Decision / Status / Consequences).

Filename: `NNNN-short-kebab-title.md` (zero-padded sequence).

Statuses: `Proposed`, `Accepted`, `Deprecated`, `Superseded by NNNN`.

For deferred decisions, use `Accepted (deferred)` and note the trigger that
would re-open the question.
